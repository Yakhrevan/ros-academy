# ROS Academy

Interactive robotics learning platform: Linux fundamentals → programming → ROS 2 core and internals → simulation → autonomy → embedded integration → industrial deployment.

Primary learning environment: ROS 2 Humble on Ubuntu 22.04.

## Development

This project uses React, TypeScript, and Vite. Run `npm install` then `npm run dev`.

The first release focuses on the dashboard, reusable lesson structure, Linux command simulations, ROS 2 message-flow visualization, quick challenges, and learning progress. Browser demos are conceptual simulations, not a live ROS runtime.
